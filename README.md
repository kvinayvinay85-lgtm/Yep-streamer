# 🎬 YepStreamer — Enterprise Streaming Platform

YepStreamer is a next-generation streaming platform built with React, Vite, Tailwind CSS, and full enterprise admin management, simulcast scheduling, and permanent storage capabilities.

---

## 🚀 How to Deploy YepStreamer on GitHub & GitHub Pages

Follow these simple steps to push your website to GitHub and publish it live for free:

### Step 1: Create a Repository on GitHub
1. Go to [GitHub.com](https://github.com) and log in.
2. Click **New Repository** (`+` icon at top right).
3. Name your repository `yepstreamer` (or any name you prefer).
4. Leave it as **Public** and click **Create repository**.

### Step 2: Push Code to GitHub
Open your terminal in the workspace folder and run:

```bash
git init
git add .
git commit -m "Initial commit - YepStreamer release"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/yepstreamer.git
git push -u origin main
```
*(Replace `YOUR_GITHUB_USERNAME` with your actual GitHub username)*

---

### Step 3: Enable GitHub Pages
1. Go to your repository settings on GitHub (`Settings` -> `Pages`).
2. Under **Build and deployment**:
   - **Source**: Select **GitHub Actions**.
3. That's it! GitHub Actions (`.github/workflows/deploy.yml`) will automatically build and publish your website.
4. Your website will be live at:
   `https://YOUR_GITHUB_USERNAME.github.io/yepstreamer/`

---

## ⚡ Alternative: Deploy in 1-Click on Vercel
1. Go to [Vercel.com](https://vercel.com) and sign in with GitHub.
2. Click **Add New Project** and select your `yepstreamer` repository.
3. Click **Deploy**! Your site will be live instantly on a free `.vercel.app` domain.
